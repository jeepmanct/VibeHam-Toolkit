# Reference Implementation (Scrubbed)

This directory contains a scrubbed copy of the original web/API codebase that inspired VibeHam Toolkit.

All personally identifying information has been removed or templated:

- Callsign replaced with `{CALLSIGN}`
- GitHub username replaced with `{GITHUB_USER}`
- Host/machine references replaced with `{HOST}`
- Data directory paths replaced with `{DATA_DIR}`
- Deployment-specific systemd units, Caddyfile, and `.env` files removed
- Password/QRZ-key setup scripts removed

This code is provided for reference only. The iOS app lives at the repository root under `VibeHamToolkit/`.
